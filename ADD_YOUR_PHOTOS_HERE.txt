⚠️ IMPORTANT - Filename Rules:

❌ WRONG:
   Youth-Summit.jpg      (capital letters)
   youth summit.jpg      (space instead of hyphen)
   youth-summit.JPG      (uppercase extension)
   youth_summit.jpg      (underscore instead of hyphen)

📞 TROUBLESHOOTING:
───────────────────────────────────────────────────────────────────

❓ Images not showing?
   → Check filenames match exactly (case-sensitive!)
   → Make sure files are in src/assets/gallery/ folder
   → Try hard refresh: Ctrl + F5
   → Check console for errors: F12

❓ Build error?
   → Make sure ALL 10 files exist
   → Check file extensions are .jpg or .png
   → Restart dev server: Ctrl+C, then "npm start"

❓ Slider shows broken images?
   → Verify files are in correct folder
   → Check filenames have no typos
   → Ensure file extensions match (.jpg not .JPG)
