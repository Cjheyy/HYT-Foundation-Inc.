# 📸 Paano Palitan ang Pictures - SUPER SIMPLE!

## 🎯 Mabilis na Guide

### 1️⃣ Puntahan ang Folder

**Press:** `Windows Key + E`

**Navigate to:**
```
C:\Users\Christian Mabbayad\Downloads\HYTFoundation\hyt-foundation\src\assets\gallery
```

**Or follow this path:**
```
hyt-foundation → src → assets → gallery
```

---

### 2️⃣ Ihanda ang Pictures

**Kailangan:** 10 pictures (JPG or PNG)

**I-rename to exactly:**
1. `youth-summit.jpg`
2. `ojt.jpg`
3. `workshop.jpg`
4. `outreach.jpg`
5. `awards.jpg`
6. `empowerment.jpg`
7. `career.jpg`
8. `achievement.jpg`
9. `partnership.jpg`
10. `innovation.jpg`

**⚠️ Important:** Lowercase, with hyphen kung may hyphen, `.jpg` extension!

---

### 3️⃣ Copy ang Pictures

**Simple method:**
1. Select all old files sa gallery folder
2. Press `Delete`
3. Copy your 10 new renamed photos
4. Paste sa gallery folder

**Done!** ✓

---

### 4️⃣ Refresh Browser

1. Go to: `http://localhost:3000`
2. Press: `Ctrl + F5`
3. Scroll to "Our Accomplishments"
4. **Your pictures should appear!** 🎉

## 💡 Quick Tips

### Wala pang 10 pictures?
- Copy 1 picture, paste 10 times
- Rename each to match the list
- Puwede yan for testing!

### From phone?
1. Connect phone to PC (USB)
2. Copy photos from phone
3. Rename
4. Paste sa gallery folder

### Pictures too big?
- Use TinyPNG.com to compress
- Target: under 500KB each

## ⚠️ Common Mistakes

| ❌ MALI | ✅ TAMA |
|---------|---------|
| `Youth-Summit.jpg` | `youth-summit.jpg` |
| `youth summit.jpg` | `youth-summit.jpg` |
| `youth_summit.jpg` | `youth-summit.jpg` |
| `youth-summit.JPG` | `youth-summit.jpg` |

**Remember:** Exact match lang! Case-sensitive!

---

## 🆘 Hindi lumalabas ang pictures?

**Try:**
1. ✅ Check filenames (exact match?)
2. ✅ Check folder location (nasa gallery folder?)
3. ✅ Hard refresh: `Ctrl + F5`
4. ✅ Restart server: `Ctrl + C`, then `npm start`
5. ✅ Check browser console: `F12` (may errors?)
