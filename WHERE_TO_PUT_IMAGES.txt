🎯 QUICK STEPS:
───────────────────────────────────────────────────────────────────

1. Open File Explorer
2. Navigate to: hyt-foundation\public\images\gallery
3. Copy your 10 photos there
4. Open: hyt-foundation\src\data\galleryData.js in VS Code
5. Change each "image:" line to point to your photos
6. Save the file (Ctrl + S)
7. Refresh browser (Ctrl + F5)
8. Done! 🎉

💡 TIPS:
───────────────────────────────────────────────────────────────────

✓ Image names: Use simple names (no spaces!)
   ✅ Good: photo1.jpg, event-2024.jpg, summit.jpg
   ❌ Bad: my photo 1.jpg, Event (2024).jpg

✓ Image size: Keep under 500KB each
   - Right-click photo → Properties → Check size
   - Use online compressor if needed: tinypng.com

✓ Image format: JPG or PNG
   ✅ Good: .jpg, .jpeg, .png
   ❌ Bad: .webp, .gif, .bmp

✓ Path format: Must start with /images/gallery/
   ✅ Good: "/images/gallery/photo.jpg"
   ❌ Bad: "images/gallery/photo.jpg" (missing /)
   ❌ Bad: "/public/images/gallery/photo.jpg" (has /public)

📧 NEED HELP?
───────────────────────────────────────────────────────────────────

Can't find the folders?
→ Make sure you're in the hyt-foundation project folder!

Images not showing?
→ Check the filename matches exactly (case-sensitive!)
→ Hard refresh: Ctrl + F5

Still using Unsplash photos?
→ Make sure you saved galleryData.js
→ Restart the server: Stop (Ctrl+C) then "npm start"
