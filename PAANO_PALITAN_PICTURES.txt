🔄 STEP 3: PALITAN ANG FILES
───────────────────────────────────────────────────────────────────

OPTION A - Simple Replace:
   1. Bukas ang gallery folder
   2. I-select lahat ng files (Ctrl + A)
   3. Press Delete
   4. Copy ang 10 new pictures mo
   5. Paste sa gallery folder (Ctrl + V)

OPTION B - Direct Replace:
   1. Bukas ang gallery folder
   2. Copy ang 1st new picture mo (youth-summit.jpg)
   3. Paste sa gallery folder
   4. Mag-prompt: "Replace file?"
   5. Click YES
   6. Ulitin para sa lahat ng 10 pictures

OPTION C - Drag and Drop:
   1. Bukas ang 2 folders side by side:
      - Left: Gallery folder
      - Right: Folder ng new pictures mo
   2. Drag and drop ang new pictures
   3. Click YES sa "Replace files?"

✅ STEP 4: TINGNAN SA BROWSER
───────────────────────────────────────────────────────────────────

1. Bukas ang browser mo (http://localhost:3000)

3. Scroll down sa "Our Accomplishments" section
4. Tignan ang slider - dapat bagong pictures na! 🎉

KUNG HINDI PA RIN LUMABAS:
   - Check kung correct ang filenames

💡 TIPS SA PAG-RENAME NG FILES
───────────────────────────────────────────────────────────────────

WINDOWS QUICK RENAME:
   1. Select ang file
   2. Press F2
   3. Type new name
   4. Press Enter

BATCH RENAME (kung marami):
   1. Select all files
   2. Right-click → Rename
   3. Type: "photo"
   4. Press Enter
   5. Files become: photo (1).jpg, photo (2).jpg, etc.
   6. Manually rename each to correct names

🆘 TROUBLESHOOTING
───────────────────────────────────────────────────────────────────

Problem: Pictures hindi lumalabas?
Solution:
   1. Check filenames - dapat exact match
   2. Check folder location - dapat sa src/assets/gallery
   3. Hard refresh - Ctrl + F5
   4. Restart server - Ctrl + C, then "npm start"

Problem: Build error?
Solution:
   1. Check kung 10 files talaga (complete)
   2. Check kung lahat ay .jpg or .png
   3. Check kung walang special characters sa filename

Problem: Blurry pictures?
Solution:
   1. Use higher resolution images (at least 800px wide)
   2. Don't compress too much
   3. Use original quality photos
