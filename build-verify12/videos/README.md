## Video Specifications:
- Format: MP4 (H.264)
- Aspect Ratio: 16:9 (recommended)
- Resolution: 1920x1080 or 1280x720
- Duration: 1-3 minutes recommended
- File size: Keep under 50MB per video for web performance
