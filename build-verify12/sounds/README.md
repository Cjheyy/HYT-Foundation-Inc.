# Sound Files Directory

This directory is for hover sound effects used in the gallery.

## Required File:
- `gallery-hover.mp3` - Subtle hover sound for gallery cards (recommended: 0.1-0.3 seconds, low volume)

## Recommendations:
- Use subtle UI sounds (soft click, gentle whoosh, or soft beep)
- Keep file size small (< 50KB)
- Volume should be quiet and non-intrusive
- Duration: 100-300ms

## Free Sound Resources:
- https://mixkit.co/free-sound-effects/
- https://freesound.org/
- https://soundbible.com/

If the sound file doesn't exist, the gallery will work normally without audio errors.
