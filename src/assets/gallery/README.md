## ✅ Image Requirements

**Format:** JPG or PNG  
**Recommended size:** 
- Width: 800-1200 pixels
- Height: 1000-1500 pixels
- Portrait orientation works best!

**File size:** Keep under 500KB each
- Use TinyPNG.com to compress if needed

**Naming:** Exact names above (lowercase, with hyphens)

## 🎨 Tips for Best Results

### Photography Tips:
- ✅ Use well-lit photos
- ✅ Show people/action (not empty rooms)
- ✅ Portrait orientation preferred
- ✅ High resolution (at least 800px wide)
- ❌ Avoid blurry photos
- ❌ Avoid very dark photos

### Editing Tips:
- Brighten photos if too dark
- Crop to portrait orientation (vertical)
- Compress large files (use TinyPNG.com)
- Keep faces visible if possible

## ⚠️ Important Notes

**Exact filenames required!**
- ✅ `youth-summit.jpg` (correct)
- ❌ `Youth Summit.jpg` (wrong - has capital letters)
- ❌ `youth summit.jpg` (wrong - has space)
- ❌ `youth-summit.JPG` (wrong - extension must be lowercase)

**If image doesn't show:**
1. Check filename matches exactly
2. Check file is in this folder
3. Check file extension is .jpg or .png
4. Try hard refresh (Ctrl + F5)
5. Check browser console for errors (F12)
