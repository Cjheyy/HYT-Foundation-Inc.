# 📹 How to Manually Add Videos to Gallery

## 🎯 Super Simple Guide

### Step 1: Get or Create Your Videos
- Record videos from your HYT Foundation events
- Or download free stock videos from Pexels/Pixabay
- Keep them under 50MB each for web performance

### Step 2: Prepare Video Files
Convert to **MP4 format** if needed:
- Use free online converter: https://cloudconvert.com/
- Or use VLC Media Player: File → Convert/Stream
- Recommended settings: H.264, 720p or 1080p

### Step 3: Name Your Videos Exactly Like This
The system expects these **exact filenames**:

```
youth-leadership.mp4
ojt-partnership.mp4
skills-training.mp4
community-outreach.mp4
excellence-awards.mp4
innovation-showcase.mp4
```

⚠️ **Important:** The filenames must match exactly (lowercase, with hyphens)!

### Step 4: Copy Videos to Public Folder
1. Open your project folder: `hyt-foundation`
2. Navigate to: `public/videos/`
3. **Drag and drop** or **copy-paste** your 6 MP4 files there

Your folder structure should look like:
```
hyt-foundation/
└── public/
    └── videos/
        ├── youth-leadership.mp4
        ├── ojt-partnership.mp4
        ├── skills-training.mp4
        ├── community-outreach.mp4
        ├── excellence-awards.mp4
        └── innovation-showcase.mp4
```

### Step 5: Test It!
1. Open your browser: http://localhost:3000
2. Scroll to "Our Accomplishments" section
3. Click anywhere on the page first (activates audio)
4. Hover over cards - you'll hear a beep sound
5. Click any card - video modal opens
6. **Your video should play automatically!** 🎉

## 💡 Tips & Tricks

### Compress Large Videos
If your videos are too big (over 50MB):
1. Use HandBrake (free): https://handbrake.fr/
2. Settings:
   - Preset: "Web"
   - Video codec: H.264
   - Quality: RF 23
   - Resolution: 1280x720 (or 1920x1080)
3. This typically reduces file size by 50-70%!

### Test One Video First
Don't have all 6 videos yet? No problem!
- Add just 1 or 2 videos
- The rest will show "Coming Soon"
- Everything still works perfectly

### Use Same Video for Testing
Want to test quickly?

## 🆘 Troubleshooting

### Video doesn't play?
- Check filename matches exactly
- Verify MP4 format (not MOV, AVI, etc.)
- Try smaller file size (compress if needed)
- Check browser console for errors (F12)

### Still shows "Coming Soon"?
- Verify file is in `/public/videos/` folder
- Check filename spelling (case-sensitive!)
- Hard refresh browser (Ctrl+F5)
- Check file isn't corrupted (try playing in VLC)

### Sound doesn't play?
- Click anywhere on page first (browser requirement)
- Check browser isn't muted
- The sound is very quiet (intentionally subtle)
- Try adjusting volume
